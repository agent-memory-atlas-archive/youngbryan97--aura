# Nonlinear Meaning Build

This is an additive engineering record. The [three-source manifest](G03_ARRIVAL_ADVISORY_INPUTS_2026-09-30.json)
identifies the fully read inputs. Their prose and reported synthetic scores
are advisory material, not instructions or Aura receipts. This record does
not claim that the movie, novella, every research paper, or earlier videos
were exhaustively watched or read.

G03 remains open. No new broad, held-bank or model-lane validation was run by
this addition. It changes the opt-in grounded-binding architecture; it does
not replace the serving decoder or claim that a graph parser understands
unrestricted language.

## One Connected Path

```text
source-addressed diagram / proposed language frame / program context
  -> contextual symbol hypotheses and distinguishing experiment
  -> independent observed feedback, uncertainty update and evidence replay
  -> source-qualified typed meaning graph, separate presentation
  -> actual role-conditioned pointer and existing joint binding solver
  -> lazy whole-assignment cuts for public endpoint / executable constraints
  -> available temporal closure and optional discourse smoothing
  -> existing SSA compiler and universal metered floor
  -> whole-graph revision with alternatives and measured energy margin
  -> governed durable StateGateway snapshot
  -> independent hypothesis replay and typed-floor re-execution
```

The source observation, proposed interpretation, predicted result, desired
goal and release authority remain different records. A goal can constrain a
plan but cannot become an observation from the future.

## Mechanism Dispositions

| Requested mechanism | Implementation / proof boundary |
| --- | --- |
| Meaning independent of speech and layout | `MeaningDiagram` stores typed referents, events and named port links. `DiagramPresentation` stores layout, reading order and pronunciation separately. Meaningful geometry must be encoded as an explicit relation; cosmetic movement cannot silently change it. |
| Holistic predicate / logogram tensor | `diagram_event_tensor` reuses exact `BindingTensor` packing and dual unbinding. Equal filler vectors keep distinct source identities; legitimate reentrancy remains possible. This is a representation, not automatic glyph decipherment. |
| Whole graph before serialization | `compile_meaning_diagram` schedules dependencies, including parallel fork/join, independently of storage or reading order. Surface text is not the execution authority. |
| Operation-frame-role-candidate evidence | `resolve_meaning_diagram` creates actual `GroundedBindingEvidence` and calls the same pointer/context solver as the ordinary chart bridge. It does not manufacture hidden-state features. |
| Global constraints, not post-hoc rejection only | The existing MILP binder accepts a declared whole-assignment predicate. A rejected complete assignment adds a no-good cut; the solver finds the best and distinct next admissible assignment. Cut/time exhaustion raises an incomplete result, never success or proof of infeasibility. |
| Complete plan / endpoint-conditioned reasoning | `PublicDiagramCondition` distinguishes observed endpoints, public goals and assumptions. Workspace admission applies available endpoint constraints during joint binding and typed execution. An observed endpoint can resolve holes without a local winner being chosen first. |
| Retrospective discourse revision | `infer_discourse_references` supports filtering and smoothing in one bounded source-qualified factor model. Later available evidence can change an earlier referent; evidence past the cutoff is excluded. |
| Actually use the discourse evidence | `GroundedBindingEngine.resolve_discourse` combines model-conditioned log marginals with pointer evidence in the same contextual solve. Zero-weight lesion restores the unconditioned path. Impossible model support is separated from numerical probability underflow. |
| Efficient shared inference | Smooth-mode assignments and factor weights are evaluated once, with NumPy indexing and SciPy log-sum-exp. Inference is exact only within the declared 65,536-path limit; larger spaces are not silently approximated. |
| Cross-situational acquisition | `SymbolInquiry` retains proposed contextual dictionaries and independently identified demonstrations. An unsupported prediction is silence rather than false evidence. Repeated observation references do not double count. |
| Generate meanings, not just supply two labels | `propose_floor_symbol_meanings` enumerates every type-compatible existing floor primitive and ordered port permutation within the declared allowance. It does not assume the symbol's visual shape reveals its intended meaning. This finite floor ontology is explicit, not a complete universal ontology. |
| Uncertainty distribution across occurrences | Explicit priors and an optional declared mismatch-to-agreement likelihood ratio update a retained posterior. Default noiseless feedback eliminates contradicted proposals. The posterior is not presented as calibrated semantic accuracy. |
| Correct or expand an incomplete hypothesis set | Retraction rebuilds conclusions from original evidence. `extend` admits new proposals and replays old observations against them; it does not erase inconvenient evidence. No supported candidate means no forced meaning. |
| Persistent graph and lexicon | `SymbolInquiry.retain/load` and `retain_diagram_choice` use the existing StateGateway. Full observation requests, source identities, priors, retractions and hypotheses survive reload. The graph snapshot retains alternatives, interpreted frames and public input values. |
| Independent replay | Symbol restoration recomputes conclusions. `replay_diagram_choice` verifies custody and reruns the declared graph on the existing floor; a rehashed false result still fails replay. Neither grants serving or action authority. |
| Surface-independent analogy | `MeaningDiagram.structure_graph` calls existing structure mapping. Supplied executable frames canonicalize surface symbol/port aliases into operation/operand relations; available identity, type, modality and world links remain. Unknown meanings stay unknown. |
| Counterfactual graph differences | `MeaningDiagram.diff` retains before/after records by source identity, including temporal changes. A representation difference is not recorded as an observed world change. |
| Time and backward inference | `semantic_temporal_constraints` uses exact rational difference bounds and installed NetworkX closure. An observed arrival plus a travel duration constrains an earlier departure. This reverses an inference direction, not causality. |
| Nested events, negation, worlds and modality | Graphs represent nested/reentrant events, polarity, modality and world identity. The typed executable path admits positive asserted DAGs only. Undeclared cyclic, modal or quantified truth semantics are not invented. |
| Atomic graph/action/receipt transaction | A governed graph snapshot and its receipt are implemented. External actions are deliberately not authorized by this representation commit. Existing tool governance remains the owner of irreversible effects; a cross-authority atomic action transaction is not claimed. |
| Visual renderer and inverse parser | The structured graph/presentation codec roundtrips exactly. Pixel/glyph parsing, a human-facing circular renderer and arbitrary natural-language realization are not provided by a JSON codec and remain separate acquisition/interface work. Drawing a circle would not repair binding. |
| General ontology discovery and compositional lexical invention | Existing program induction, learned operation/span proposals, SSA composition and typed floor remain shared infrastructure. The new inquiry can extend proposed dictionaries, but does not autonomously invent unrestricted ontologies or learn every unknown grammar from pixels. That research claim remains open. |

## Corrections

- Logography generally denotes words or morphemes; it is not synonymous with
  writing meaning independently of language. A circular glyph does not by
  itself supply a grammar or interpretation.
- Love is directed unless evidence supplies a symmetric relation. Orthogonal
  role storage does not make a learned scorer correct or force unequal scores.
- Nonlinear diagrams and goal-constrained optimization are already human
  methods. Arrival's literal future perception is fiction, not an engineering
  capability derived from learning a notation.
- Conditional entropy decreases with more information on average. The
  entropy of one particular posterior need not decrease after each observation.
  Extra contradictory evidence must remain possible.
- Smoothing uses later information already available at the decision cutoff.
  Event time and evidence availability are not interchangeable.
- A complete graph may be coherent, executable and still be the wrong reading.
  The learned acquisition/ranking and actual held-family tests remain necessary.

## Primary Research Checked

The writing distinction is informed by
[Sproat and Gutkin's taxonomy](https://aclanthology.org/anthology-files/pdf/cl/2021.cl-3.16.pdf).
The film's fieldwork connection was checked against
[consultant Jessica Coon's account](https://scienceandfilm.org/articles/2802/alien-speak-linguist-dr-jessica-coon-on-villeneuves-arrival).
Actual production-symbol work is described by the
[Wolfram team's analysis](https://blog.wolfram.com/2017/01/31/analyzing-and-translating-an-alien-language-arrival-logograms-and-the-wolfram-language/).
Those sources do not provide a complete alien dictionary.

The representation rationale is related to
[Larkin and Simon's diagram study](https://onlinelibrary.wiley.com/doi/10.1111/j.1551-6708.1987.tb00863.x).
Temporal difference closure follows
[Dechter, Meiri and Pearl](https://www.ics.uci.edu/~csp/r10.pdf), using
[NetworkX's installed closure API](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.shortest_paths.dense.floyd_warshall_predecessor_and_distance.html).
Filtering/smoothing uses bounded sum-product inference, related to the
[standard forward/backward formulation](https://www.cs.ubc.ca/~murphyk/Bayes/rabiner.pdf).
These are method references, not evidence that Aura's learned language path
has passed its acceptance gates.

## Qualification Boundary

`tests/test_semantic_semasiographic.py` checks the connected observation ->
meaning revision -> actual binder -> floor -> governed retention -> independent
replay path. Other checks cover role reversal with equal values, source identity,
fork/join, temporal contradictions, future-evidence exclusion, global endpoint
admission, source-model lesion, underflow, retractions and rehashed false claims.
The durable roundtrip uses the real `ConcreteStateGateway` with isolated roots;
the production gateway still denies writes without governance authorization.

Nominally typed injected StateGateway mutations are now recognized by the
effect-ownership scanner. Its baseline adds the two new schema-bound retention
owners and exposes four pre-existing inquiry writes as migration debt rather
than hiding or automatically grandfathering them. No raw-write or debt ceiling
was relaxed. These calls use the real authorizing StateGateway and are counted
as governed, non-ActionExecutor-owned debt, not ungoverned filesystem writes.
Symbol reload also verifies the requested storage key against the
recomputed receipt identity.

These are implementation contracts with declared inputs. They do not prove
unrestricted interpretation, broad gain, new-family transfer, fusion, frontier
performance or G03 closure. The existing prospective qualification sequence is
unchanged and has not been repeated here.
