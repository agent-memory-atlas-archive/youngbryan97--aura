# Native source intervention plan, before model evaluation

The 72-case native grammar result used fixed, exposed request templates. It
established that the fitted model can produce the withheld three-step programs,
but it did not show whether the model reads the operation requested in each
source. This development study changes one final operation clause per request
while retaining its public values, earlier clauses, register references, and
question. The complete corpus is generated by
`tools/semantic_native_operation_interventions.py`.

## Frozen inputs

- Generator SHA-256:
  `3a27b2413bc5ceb52f507c0e6eacd7fa37a447fcbca278febb8a17405ff5844f`.
- Seed: `2718283`. The generator uses one fresh example in each of the 24
  schema-domain cells, then flips the final operation by the fixed mapping
  `add<->sub`, `mul<->idiv`. It rejects a pair if the change leaves the exact
  answer unchanged. The seed was chosen using that outcome check, before any
  model evaluation. This is development evidence, not a random sample of all
  possible requests.
- The ordered list of 48 source SHA-256s has SHA-256
  `a60ec5c814509c47824b009faead357c8439621e9ca51cd3e9ce71e7bfef618b`
  when encoded as compact JSON. All 48 are distinct, and none appears among
  the fitted checkpoint's fit, calibration, or held source identities. They
  also differ from the earlier 72 development source texts.
- The model, tokenizer, selected fitted checkpoint, grammar, max depth, and
  scoring rule must be pinned by each evaluation plan. No intervention target
  may enter the scorer, search, or program proposal stage.

## Measurement

Run both requests in each pair with the same bounded grammar. Record every
operation and register choice, completion status, exact program, exact answer,
elapsed time, and source/plan receipt. A pair passes only if both programs
are structurally equivalent to their respective targets and both answers are
correct. Report the pair count, individual-row count, and any regression from
the unmodified to modified request. A source-responsive pair must also change
the final operation while preserving the two earlier program instructions and
the operand register indices. Independently reconstruct the corpus and replay
the saved decisions and programs. Timeouts and incomplete programs count as
failures; no row replacement or threshold change follows inspection.

Compare the fitted arm with the unfitted model under the same grammar and
source order. This comparison can show whether fitting improves this bounded
behavior. It cannot by itself isolate semantic learning: the fitted arm also
learned the native output wire. A source-blind but wire-trained control, new
syntax families, public input grounding, and fresh powered replication remain
separate obligations. No result from this plan alone closes G04, G06, G07,
or G09, or authorizes serving or fusion.
