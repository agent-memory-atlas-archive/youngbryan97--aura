cohort. The native grammar evaluator now reconstructs the existing validation

## Population and Coordinates

Each split contains 500 requests: arithmetic 128, cataphoric 48, fork/join 192,
natural alias 12, natural source 24, reserved alias 48, and role binding 48.
All 1,764 retained source examples have a complete public literal inventory.
The corpus's annotated register order often differs from the order in which
literals occur in the request. Comparing those coordinates without relabeling
would report correct source-order graphs as binding errors.

The loader maps annotated input spans to public literal character spans. It
remaps only input references and the corresponding definition spans; computed
registers retain their identity. An independent execution check requires the
relabeled grading program to preserve its value. Equal-valued inputs are matched
by span, not by value. This transforms grading annotations, not source text or
model evidence. It does not infer the correct interpretation for the scorer.

Requests are interleaved across cohorts, sorted by source digest within each
cohort. Labels and model scores cannot determine selection order. A version-6
plan binds the report, every manifest, split, population, ordering, and grading
coordinate contract. Independent verification reconstructs that basis and
reexecutes the saved program and choice evidence.

generation for grading. No serving, fusion, G03 closure, or broad reasoning
